# Changelog

## [1.0.0] - 2025-11-12

### Added
- Migración completa a Next.js 14 con TypeScript y Tailwind CSS.
- Componentes hero, características, mockups animados con Framer Motion.
- Formularios de beta y feedback conectados a Supabase con protección anti-bot.
- Integración con Supabase Edge Function para envío de emails vía Zoho Mail.
- Plantillas HTML/texto para confirmaciones, agradecimientos y alertas internas.
- Scripts de extracción de contenido (`scripts/extract-current-site.ts`) y backup (`scripts/backup-supabase.ts`).
- Configuración de SEO (Open Graph, Twitter Card, JSON-LD, sitemap y robots).
- Pipeline CI/CD en GitHub Actions con despliegue a Vercel.
- Documentación completa (`README.md`, `MIGRATION.md`, `DEPLOY_NOTES.md`, `CHECKLIST.md`).
- Tests unitarios con Jest + React Testing Library para componentes críticos.
